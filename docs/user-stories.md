# User stories (5-сабақ)

Пішім: «[рөл] ретінде мен [әрекет] қалаймын, себебі [пайда]»

MoSCoW: M — міндетті (Must), S — керек (Should), C — болса жақсы (Could), W — бұл нұсқада жоқ (Won't)

| ID   | Story | M/S/C/W | Қабылдау шарты (тексерілетін) |
|------|-------|---------|--------------------------------|
| US-1 | **teacher** ретінде мен тест құрып, оған 2–6 нұсқалы сұрақ қосқым келеді, себебі сабаққа бақылау керек | M | Атау 3–200 таңба, әйтпесе → 422; әр сұрақта 2–6 нұсқа, дәл бір дұрыс индекс; бұзылса → 422 |
| US-2 | **teacher** ретінде мен тестті жариялағым келеді, себебі тек жарияланған тестті студент көреді | M | Сұрағы 0 тест жарияланбайды → 400; жарияланған тест `is_published=true` болады |
| US-3 | **student** ретінде мен жарияланған тестті тапсырып, ұпайымды бірден көргім келеді, себебі өз деңгейімді білгім келеді | M | Жауап жіберілген сәтте жауапта `score` қайтады; дұрыс жауаптар тізімі студентке қайтарылмайды; тапсырылмаған тестке → 400 |
| US-4 | **teacher** ретінде мен сабақ мәтінінен AI (Ollama) сұрақ ұсынысын алғым келеді, себебі қолмен жазудан уақыт қалам | M | AI қолжетпесе → ескерту + қолмен қосу жолы жұмыс істей береді (fallback); ұсыныстар міндетті түрде мұғалімнің қолымен қосылғанда ғана сақталады |
| US-5 | **student** ретінде мен бұрынғы нәтижелерімді көргім келеді, себебі прогрессімді бақылармын | S | Тек өзімнің нәтижелерім ғана; басқаныкі → 404/403 |
| US-6 | **teacher** ретінде мен тестімнің орташа ұпайын көргім келеді, себебі сынып деңгейін бағалаймын | C | Тек иесі-мұғалім көреді; әзірге — қолмен есептеуге рұқсат (API қажет емес) |
| US-7 | Тестке уақыт шектеу (таймер) қосу | W | Бұл нұсқада жоқ |

**MVP шегі:** US-1 … US-4 (барлық Must).

Рөлдер: 2 (teacher, student). Әр Must story — кемінде бір endpoint пен кестеге
(6-сабақта) сәйкес келеді.
