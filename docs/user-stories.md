# User stories (5-сабақ)

Пішім: «[рөл] ретінде мен [әрекет] қалаймын, себебі [пайда]»

MoSCoW: M — міндетті (Must), S — керек (Should), C — болса жақсы (Could), W — бұл нұсқада жоқ (Won't)

| ID   | Story | M/S/C/W | Қабылдау шарты (тексерілетін) |
|------|-------|---------|--------------------------------|
| US-1 | **student** (дайындалушы) ретінде мен жарияланған практикалық тестті тапсырып, ұпайымды бірден көргім келеді, себебі өз деңгейімді өлшеймін | M | Жауапта `score` қайтады; дұрыс жауаптар (`correct_index`) студентке қайтарылмайды; жарияланбаған тестке тапсыру → 400 |
| US-2 | **student** ретінде мен AI (Ollama) менің әр қателі сұрағымның дұрыс шешімін түсіндіргім келеді, себебі қатемді түсінемін | M | Review тек менің attempt-ім үшін (басқаныкі → 404/403); AI қолжетпесе → ескерту + дұрыс жауап кілті (fallback) |
| US-3 | **student** ретінде мен өз әлсіз тақырыптарымның картасын көргім келеді, себебі дайындықты жоспарлаймын | M | Тек менің attempt-терімнен есептеледі; attempt саны 2-ден аз болса → «дерек жеткіліксіз» жауабы |
| US-4 | **mentor** ретінде мен өз топым үшін практикалық тест құрып, жариялап, топтың жиі қателескен тақырыптарын көргім келеді, себебі сабақтарымды жоспарлаймын | M | Тест құру/жариялау тек mentor (student → 403); сұрағы 0 тест жарияланбайды → 400; топ статистикасы тек mentor-ға |
| US-5 | **student** ретінде мен бұрынғы attempt-терімді көргім келеді, себебі прогрессімді бақылаймын | S | Тек өзімнің attempt-терім; басқаныкі → 404 |
| US-6 | **mentor** ретінде мен топ оқушысының attempt-іне кері байланыс жазғым келеді, себебі бағыт беремін | C | Тек өз тобындағы оқушының attempt-іне |
| US-7 | Геймификация (сериялар, рейтинг) және оқу еске салу (reminders) | W | Бұл нұсқада жоқ |

**MVP шегі:** US-1 … US-4 (барлық Must).

Рөлдер: 2 (student, mentor). Әр Must story — кемінде бір endpoint пен кестеге
сәйкес (6-сабақ: `docs/api.md` → «Сәйкестік» бөлімі).
