## П2 · .gitignore және README (FAST)

**Промпт:** «Python (FastAPI) + Next.js жобасы үшін .gitignore жаса. Міндетті: .env, .venv/, __pycache__/, node_modules/, .next/, *.log. README.md қаңқасын жаса: жоба атауы, мақсаты (1 сөйлем), «Іске қосу» (бос бөлім). .gitignore-дың әр жолына бір сөйлемдік түсіндірме бер. git commit-ті өзің жасама.»

**.gitignore түсіндірмесі (әр жолға):**
- `.env` — құпиялар мен DB коннектинг деректері репозиторийге түспейді
- `.venv/` — виртуалды орта `python -m venv .venv` арқылы қайта жасалады
- `__pycache__/` — Python bytecode кэш папкасы
- `*.pyc` — компиляцияланған Python файлдары
- `node_modules/` — Node.js тәуелділіктері `npm install` арқылы қайта орнатылады
- `.next/` — Next.js құрастыру кэш папкасы
- `*.log` — қолданба журналдары тарихта сақталмайды

**Тексеру:** `.env` шынымен `.gitignore`-да; `git status`-та `.env` көрінбейді.

## Демо · hello.py (PLANNING)

**Промпт:** «hello.py скрипті жаса: атыңды сұрап, «Сәлем, <аты>! Бүгін <күн.ай.жыл>» деп шығарсын. Тек стандартты кітапхана. Алдымен жоспарды көрсет, команданы мен рұқсат бергенде ғана іске қос.»

**Жоспар:** 1) `argparse` арқылы `--name` аргументін қабылдайды; 2) аргумент болмаса `input()` арқылы сұрайды; 3) `datetime.date` арқылы күнді форматтайды; 4) шығарады.

**Тексеру:**
